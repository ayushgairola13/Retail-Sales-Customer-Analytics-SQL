# Retail Sales & Customer Analytics | SQL
## Project Overview

This project focuses on analyzing retail sales, customer, and product data using SQL to generate meaningful business insights and support data-driven decision-making.
The analysis uses SQL queries to explore sales performance, identify top- and low-performing products, evaluate sales trends, understand customer purchasing behavior, and identify repeat-purchase patterns. The project demonstrates practical SQL skills including data exploration, filtering, aggregation, joins, subqueries, Common Table Expressions (CTEs), CASE statements, and analytical functions.

## Tools & Skills
- SQL
- Data Cleaning & Exploration, Data Aggregation
- Joins, Subqueries
- Common Table Expressions (CTEs)
- CASE Statements, Window Functions
- GROUP BY & HAVING
- Date & Time Analysis
- Customer Segmentation, Sales Analysis


## SQL Concepts Used
The project demonstrates the practical application of key SQL concepts and techniques, including SELECT, WHERE, GROUP BY, HAVING, ORDER BY, JOINs, CASE statements, Subqueries, Common Table Expressions (CTEs), Aggregate Functions, Window Functions, and Date Functions.
Common aggregate functions such as SUM(), COUNT(), AVG(), MIN(), and MAX() were used to summarize and analyze the retail data.


## Key Insights
- Identified top-performing products based on sales performance.
- Identified low-performing products that may require further business evaluation.
- Analyzed sales trends to understand changes in retail performance.
- Identified high-value customers based on purchasing activity.
- Segmented customers according to purchase value and behavior.
- Identified repeat customers and analyzed their purchasing patterns.
- Highlighted potential customer retention opportunities through repeat-purchase analysis.

## Key Takeaway
This project demonstrates how SQL can be used to transform raw retail transaction data into actionable business insights. By combining sales analysis, product performance evaluation, customer segmentation, and repeat-purchase analysis, the project provides a practical framework for understanding retail performance and identifying opportunities for customer retention and business growth.
